# DonaDoc Frontend

Interfaz web (React 18 + Vite + TypeScript) de **DonaDoc**. Proyecto del *Diplomado en Ingeniería de Software para Aplicaciones basadas en IA*.
Autor: Santiago Andrés Castro Cruz. API: repositorio `donadoc-backend` (la arquitectura está en su `docs/arquitectura.md`).

```bash
cp .env.example .env   # variables en blanco; complete las suyas
npm ci
npm run lint && npm test
npm run dev            # /api se reenvía a http://localhost:3000
```
